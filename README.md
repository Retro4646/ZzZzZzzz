
# 🛠️ Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Retro4646/ZzZzZzzz.git
```

### 2. Install Dependencies
```bash
npm install
```
```bash
npm install xlsx react-chartjs-2 chart.js
npm install --save-dev @types/xlsx
```
